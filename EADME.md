# DocumentOCR

Программа для распознавания сканированных документов с детальным анализом.

## Возможности

- ✅ Распознавание текста (русский + английский)
- ✅ Извлечение таблиц
- ✅ Детекция изображений
- ✅ Анализ структуры документа
- ✅ Поддержка PDF и изображений
- ✅ Несколько OCR движков

## Установка

pip install -r requirements.txt
